USB mode:
Mode: -

Tips:

WINUSB is the mode for the game (chuniio / segatools). The 4K, 8K, 16K and 32K modes make the ground slider type keyboard keys instead.

Switching restarts the USB connection: the device disappears and comes back with another USB ID. Press Connect again if the page does not reconnect by itself.
