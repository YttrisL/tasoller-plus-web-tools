References

The projects that were used to build Supernova and this Toolkit.

  • segatools - the hooks that run the game; the protocols of the LED boards and of the slider that the IO4-Emulation mode reproduces.
  • chuniio-rs - the community driver for the Tasoller Plus: how the game talks to the device in WINUSB mode.
  • host-aprom - the firmware and documentation of the arcade I/O board (IO4) that the device imitates.
  • tasoller-plus - the reference code of the Tasoller Plus on its M482 chip.
  • tasoller-plus-dump-and-restore - the dump and restore tool that the Memory dump of the Toolkit follows.
