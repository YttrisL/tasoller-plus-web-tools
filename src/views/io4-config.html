Function buttons:

This firmware does not have this setting yet: flash the latest Supernova to use it.

Button 1 (FN1)
Button 2 (FN2)
Both buttons together

Each function button of the device sends the signals you pick to the game, one or several. By default button 1 sends TEST and button 2 sends SERVICE.

With signals for both buttons together, pressing the two at once sends only those, and not the ones of each button. Leave it on Nothing to send both.

Warning: if you enter the input test of the game's Test Menu, you need access to both TEST and SERVICE to exit it.

Static light gives the device no LED boards, so there are no more COM ports to set up. The air towers show the color you pick.

LED driver emulation is how the arcade hardware works: the game lights the air towers through the two LED boards of the device, which need two more COM ports to be set up.

Why static mode ? The game sends a static white 99% of the time, only switching to red at the end of the credit. Using static color allows a very similar behavior without enforcing the need to configure two additional COM ports. If you want a behavior as close to the arcade as possible, select "LED driver emulation" and configure the two new COM ports in the device manager.

Your segatools.ini configuration:

Replace these blocks in your segatools.ini. Make sure there is no other [io4], [slider] or [led15093] block anywhere else in the file: a second copy can override these settings.


      

      

        
The game finds the device on COM ports, which have to be given the numbers it expects. They depend on the dipsw3 value of the [system] block of your segatools.ini:

        

          
dipsw3SliderLeft LED boardRight LED board

To change the number of a port, open it in the device manager (it is listed as USB Serial Device), then Port Settings, Advanced, COM Port Number.

        
Hint: the three ports have the same name in the device manager. To tell them apart, open the properties of a port, go to the Details tab and pick the property Bus reported device description: it shows the name the device gave that port, Supernova Slider, Supernova Side LED L or Supernova Side LED R.
